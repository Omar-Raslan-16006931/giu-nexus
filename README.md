## ✨ Features

- 🔐 **Auth:** register, login, email OTP verification and password reset with JWT
- 🧑‍🎓 **Students:** build a profile, browse and save jobs, apply, and track applications
- 🤖 **Recommended jobs** matched to your profile using Hugging Face models
- 🏢 **Recruiters:** post and edit jobs, and review applicants
- 🛡️ **Admin dashboard:** approve recruiters and manage users and job posts
- 📚 **API docs** with Swagger, rate limiting and file uploads

## 🌐 Live Demo

- **Frontend:** https://giu-nexus-gold.vercel.app/
- **Backend:** https://giu-nexus-czvo.onrender.com

## 🛠️ Tech Stack

| Layer | Tech |
| --- | --- |
| Frontend | React, Vite, Tailwind, shadcn/ui, Axios |
| Backend | Node.js, Express, Mongoose, JWT, Nodemailer, Multer, Swagger |
| Database | MongoDB |
| AI | Hugging Face Inference |
| DevOps | Docker Compose, Vercel, Render |

## 🚀 Getting Started

```bash
# Backend
cd backend && npm install && npm start

# Frontend
cd client && npm install && npm run dev
```

Or run everything with Docker:

```bash
docker compose up
```
